Put your DXF cut file here.

With exactly one `.dxf` in this folder, every command finds it on its own, so
`kutcontour build -i artwork.jpg` is all you need to type. With more than one,
name it with `--dxf`, or pick it from the dropdown in the web interface.

`examples/sample.dxf` is a 260 × 300 mm rounded rectangle with a hanging hole;
copy it here to try the tool before your real cut file arrives.
